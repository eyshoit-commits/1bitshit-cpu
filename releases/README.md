# Release policy

1BitShit CPU keeps source code in the repository and publishes compiled deliverables through GitHub Releases.

Do not commit complete repository copies as release folders.

Release assets should be generated by CI from a tagged commit and contain only the component they name:

- `bitshit-cli-<version>-<platform>.<archive>`
- `bitshit-engine-<version>-<platform>.<archive>`
- `bitshit-kernel-cpu-<version>-<platform>.<archive>`
- `bitshit-driver-cpu-<version>-<platform>.<archive>`

Each archive must include its version, target triple, source commit, checksum and license notices.

Create a separate repository only when a component has an independent source tree, build lifecycle, tests and versioning. Branches are for development changes, not permanent product editions.
